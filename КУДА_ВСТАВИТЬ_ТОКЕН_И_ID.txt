КУДА ВСТАВИТЬ ТОКЕН БОТА И СВОЙ ID

Откройте файл:
C:\Users\vladi\Desktop\TelegramBotMessage\business_mute_bot.py

Менять нужно только две строки внутри функции main().
Номера строк указаны для текущей версии файла. Если они сдвинутся,
найдите строки по тексту, приведённому ниже.


1. ТОКЕН БОТА — СТРОКА 276

Сейчас там написано:
    token = os.environ.get("BOT_TOKEN", "").strip()

Замените всю эту строку на:
    token = "ВСТАВЬТЕ_СЮДА_ТОКЕН_ОТ_BOTFATHER"

Вместо ВСТАВЬТЕ_СЮДА_ТОКЕН_ОТ_BOTFATHER вставьте настоящий токен
целиком: цифры, двоеточие и всю часть после него. Кавычки оставьте.


2. ID ВЛАДЕЛЬЦА — СТРОКА 277

Сейчас там написано:
    owner = os.environ.get("OWNER_ID", "").strip()

Замените всю эту строку на:
    owner = "123456789"

Вместо 123456789 вставьте числовой ID СВОЕГО личного аккаунта Telegram,
к которому подключаете бота. Кавычки обязательно оставьте.
Нужен ID владельца, а не ID бота или собеседника.


КАК ДОЛЖНЫ ВЫГЛЯДЕТЬ ЭТИ ДВЕ СТРОКИ ВМЕСТЕ

    token = "ВАШ_НАСТОЯЩИЙ_ТОКЕН"
    owner = "ВАШ_ЧИСЛОВОЙ_ID"

Сохраните четыре пробела в начале каждой строки: обе строки находятся
внутри функции main(). После замены сохраните файл сочетанием Ctrl+S.
Другие строки менять не нужно. Файлы в папке .venv не редактируйте.

После такой замены программа будет брать токен и ID прямо из кода.
Отдельно задавать BOT_TOKEN и OWNER_ID в PowerShell уже не требуется.
Файл с настоящим токеном не публикуйте: токен даёт доступ к вашему боту.

Если вам нужен ID СОБЕСЕДНИКА для удаления его сообщений, в код
его вставлять не нужно. Его указывают в чате с ботом командой:
/mute ID_СОБЕСЕДНИКА
