КАК СОЗДАТЬ TELEGRAM-БОТА И ПОЛУЧИТЬ API-ТОКЕН

1. Откройте Telegram и перейдите к официальному боту BotFather:
   https://t.me/BotFather

2. Нажмите «Запустить» / Start.

3. Отправьте команду:
   /newbot

4. BotFather попросит название бота.
   Напишите любое название, например: Мой бот.

5. Затем BotFather попросит username — уникальное имя бота.
   Оно должно заканчиваться на bot, например: my_example_bot.
   Если имя занято, придумайте другое.

6. После создания BotFather пришлёт сообщение с API-токеном.
   Найдите строку примерно такого вида:
   123456789:AAExampleSecretKey
   Это вымышленный пример. Ваш токен будет другим.

7. Скопируйте токен целиком: цифры, двоеточие и всю часть после него.
   Это API-токен созданного бота. Для одного бота нужен один токен.

ЕСЛИ БОТ УЖЕ СОЗДАН

1. Откройте https://t.me/BotFather.
2. Отправьте /mybots.
3. Выберите своего бота.
4. Нажмите API Token, чтобы посмотреть его токен.
